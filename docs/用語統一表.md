# 用語統一表

ctm と計測成果物で使う語を 1 概念 1 名称に固定する。
各概念に **日本語（表示用）／ JSON フィールド／ Go 識別子** の 3 表記を定め、それ以外は使わない。

---

## 1. 数える単位 ★最重要

同じ会話が「245」「154」「87」と 3 通りに数えられる。この曖昧さが実際に二重計上バグを生んだ。

| 概念 | 定義 | 日本語 | JSON | Go |
|---|---|---|---|---|
| ログ行 | jsonl の物理 1 行 | **行** | `lines` | `lines` |
| ターン | user / assistant の発話 1 つ（表示単位） | **ターン** | `turns` | `turns` |
| メッセージ | **重複排除後の課金単位**。`message.id + requestId` で一意 | **メッセージ** | `messages` | `Messages` |

- 「メッセージ」は課金単位**のみ**を指す。表示の並びは「ターン」と呼ぶ。
- 廃止: `msgs` / `Entry` / `entries` / `events` / 「通」/「明細」/「やり取り」を件数の意味で使わない。
- 実例: 245 行 → 116 ターン → 44 メッセージ（重複行 28）。

## 2. トークン種別

現状 `cache-read` / `cr` / `cread` / `cache_read` / `CacheRead` の 5 表記が混在。

| 概念 | 日本語 | JSON | Go |
|---|---|---|---|
| 新規入力 | **input** | `input_tokens` | `Input` |
| キャッシュ書き込み 5分 | **cache-write 5m** | `cache_write_5m_tokens` | `CacheWrite5m` |
| キャッシュ書き込み 1時間 | **cache-write 1h** | `cache_write_1h_tokens` | `CacheWrite1h` |
| キャッシュ読み出し | **cache-read** | `cache_read_tokens` | `CacheRead` |
| 出力 | **output** | `output_tokens` | `Output` |
| 上記の合計 | **合計トークン** | `total_tokens` | `Total()` |

- 日本語文中でも英語表記のまま使う（「キャッシュ読み」等に訳さない）。
- 廃止: `cr` / `cw1h` / `cw5m` / `cread` / `cw1` — 表の見出しでも省略しない。

## 3. 主体（誰が使ったか）

| 概念 | 定義 | 日本語 | JSON | Go |
|---|---|---|---|---|
| セッション | Claude Code の 1 起動。`<sessionId>.jsonl` 1 本に対応 | **セッション** | `session` | `Session` |
| セッション ID | 上記の UUID。ログのファイル名と同一 | **セッション ID** | `session_id` | `SessionID` |

- 短縮形 `sid` はスクリプト内部の局所変数のみ可。出力・文章では使わない。
- 8 文字だけ示すときは「セッション ID の先頭 8 文字」と明記する。

## 4. 場所（どこで使ったか）

現状 `project` / `note` / ワークスペース / ディレクトリ が同じものを指していて不透明。

| 概念 | 定義 | 日本語 | JSON | Go |
|---|---|---|---|---|
| 作業ディレクトリ | メッセージ発生時の `cwd` の末尾フォルダ名 | **作業ディレクトリ** | `cwd_name` | `CWDName` |
| ログ格納先 | `~/.claude/projects/` 直下の格納フォルダ | **ログ格納先** | `log_dir` | `LogDir` |

- 現行の `project` / `Project` / `note` は **`cwd_name` に改名**する。「プロジェクト」は使わない
  （`~/.claude/projects` の意味と衝突し、実際に win/context の取り違えを招いた）。
- `note` は用途不明の汎用名なので廃止。

## 5. 計測の枠組み

| 概念 | 定義 | 統一名 |
|---|---|---|
| 行為全体 | トークン消費を測ること | **計測**（「測定」は使わない） |
| 起点時刻 | これ以降を数える基準時刻 | **基準時刻**（`-since` の値） |
| 起点の状態 | 基準時刻における累計値 | **開始前** |
| 基準時刻以降の増分 | | **差分** |
| 生涯累計 | セッション開始からの全量 | **累計** |

- 廃止: 「ベースライン」（→ 基準時刻 / 開始前に分離）、「デルタ」。
- `baseline.md` 等のファイル名は既存のまま。本文の語だけ統一する。

## 6. 時間

3 種を必ず区別する。混同すると速度が最大 20 倍ずれる。

| 概念 | 定義 | 統一名 |
|---|---|---|
| 経過時間 | 最初と最後のメッセージの時刻差 | **経過** |
| 実稼働時間 | 10 分以上の空白を除いた稼働クラスタの合計 | **実稼働** |
| 中断 | 10 分以上メッセージが無い区間 | **中断** |

実例: 第 3 回は経過 541.9 分だが実稼働 27.3 分。$/min は **実稼働ベース**で出し、
経過ベースを併記する場合は必ず明示する。

## 7. 速度

| 概念 | 統一名 | 単位 |
|---|---|---|
| トークン消費速度 | **トークン速度** | tok/min |
| コスト消費速度 | **コスト速度** | $/min |

- 廃止: 「バーンレート」「レート」（レートは料金倍率の意味に予約）。

## 8. 料金

| 概念 | 統一名 |
|---|---|
| 金額 | **コスト**（費用・料金・金額は使わない） |
| 単価の倍率 | **レート**（cache-read = 0.1x、cache-write 5m = 1.25x、1h = 2.0x） |
| 100 万トークンあたり単価 | **リスト価格** |

コスト表記には必ず「リスト価格換算・定額プランでは実請求なし」を添える。

## 9. 入出力

| 概念 | 定義 | 統一名 |
|---|---|---|
| 人間が打った文 | `type: user` かつ text ブロックあり | **指示** |
| ツール実行結果の返送 | `type: user` かつ tool_result のみ | **ツール結果** |
| モデルの発話 | assistant の text ブロック | **応答** |
| モデルのツール呼び出し | assistant の tool_use ブロック | **ツール呼び出し** |

- 「プロンプト」は指示とツール結果の両方を含む API 入力全体を指す語なので、
  人間の入力を指す用途では使わない。**人間の入力＝指示**。
- 廃止: 「問い合わせ」「質問」「返答」「回答」。

## 10. 記録物

| ファイル | 中身 | 統一名 |
|---|---|---|
| `events.md` | メッセージ 1 件 1 行の表 | **明細** |
| `transcript-*.md` | 指示・応答の全文＋トークン | **全文記録** |
| `digest.md` | 全文を切り詰めた一覧 | **要約一覧** |
| `timeline.md` | 一定間隔の累計値 | **推移** |
| `baseline.json` | ある時点の全体集計 | **スナップショット** |

- 廃止: 「トランスクリプト」「ダイジェスト」「タイムライン」（カタカナ直訳）。

## 11. 重複

| 概念 | 定義 | 統一名 |
|---|---|---|
| 同一メッセージの複数行 | `message.id + requestId` が同じ行 | **重複行** |
| それを除く処理 | | **重複排除** |
| 除き損ねた状態 | | **二重計上** |

- 廃止: `dedup`（コード内の関数名を除く）。

---

## 適用時の注意

JSON フィールド名（2・4 節）を変更すると `-json` / `-events` の出力互換が壊れる。
既存の `measure/` 配下の生データを読むスクリプトは同時に更新すること。
